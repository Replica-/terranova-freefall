# Bug list

Every bug found and fixed while porting Terra Nova: Strike Force Centauri (English v1.09, `__FF.EXE`) to Terra Nova: Freefall. The list is kept up to date with each change, so modders, speedrunners and other port authors can use it.

There are two kinds:
- **Bugs in the original game.** The 1996 program does something wrong that DOS happened to tolerate, for example reading memory through a null pointer. The port keeps the game's behaviour exactly, so it reproduces what DOS did rather than "fixing" the game. Three fixes change how the game plays, and all are always on: G17 (the physics clock made units about a third too fast at 25 to 32 frames a second), G19 (in big fights enemies vanished without their explosion and body) and G37 (the recoil of a shot at a far locked target pushed a flying suit off across the map).
- **Bugs in the port.** Mistakes in Freefall itself, found by playing or by the frame-by-frame comparison with the DOS original (`docs/decompilation/frame-comparison.md`).

"Verification build unchanged" means the decompiled C still rebuilds a byte-identical copy of the original program.

## Reporting a bug

Run `tnfree.exe`, reproduce the problem, and attach `tnfree.log` (next to `tnfree.exe`). After a crash it names the routine it happened in and the routines on the stack. Say which mission you were in and what you did just before, and post it on GitHub (the repository's Issues tab).
